# Design System Document

This document outlines the core design principles and token decisions for our digital products.

## Theme Overview
The design theme is configured for a **dark** color mode, aiming for a modern and visually striking aesthetic.

## Color Palette
The primary brand color is derived from an impactful orange (`#FF5F00`), contributing to a vibrant and energetic feel. The overall color variant emphasizes `fidelity`, ensuring consistent and true-to-brand color representation. The neutral color for backgrounds and non-chromatic elements is set to a deep dark (`#050505`). An additional accent color is defined as `#1a1918`.

- **Primary Color:** `#FF5F00` - Used for primary actions, important highlights, and brand elements.
- **Tertiary Color:** `#1a1918` - An additional accent color for highlights, badges, or decorative elements.
- **Neutral Color:** `#050505` - Provides a dark base for backgrounds and text.

## Typography
The typography selection ensures readability and a distinct brand voice across different content types.
- **Headlines:** `spaceGrotesk` - Provides a modern and distinctive feel for titles and headings.
- **Body Text:** `manrope` - Chosen for its legibility and versatility in long-form content.
- **Labels:** `inter` - A highly functional and clear typeface suitable for interactive elements and labels.

## Shape and Form
The UI elements feature a **moderate** level of roundedness (setting `2`), offering a balanced feel that is neither too sharp nor overly soft. This provides a contemporary and approachable aesthetic.

## Spacing
The layout maintains a **normal** level of spacing (setting `2`), ensuring a good balance between content density and visual breathability. This contributes to a clean and organized user interface.
